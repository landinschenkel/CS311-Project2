# Type Matchup — Pokémon Draft Board

A browser-based Pokémon draft board powered by PokéAPI. Deal a pool of 20 random Pokémon, compare their types and battle stats, or search for a Pokémon to see its complete base-stat profile.

## Run

Open `index.html` in a modern web browser with an internet connection. Select **Deal 20 Pokémon** to build a draft pool, or search by Pokémon name or Pokédex number to open its battle spotlight.
